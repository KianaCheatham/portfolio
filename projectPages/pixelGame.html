Pixel Adventure Game

A 2D game created as a course project using Godot. I designed the pixel art character and environment assets in Photoshop, then implemented player movement, animation, and core gameplay mechanics in GDScript. I also experimented with post-processing effects, including CRT and noise to create a retro-inspired visual style.


  • Godot
  • GDScript
  • Photoshop
